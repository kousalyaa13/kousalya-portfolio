# Kousalya's Corner ✿

A playful lavender-and-butter-yellow portfolio for Kousalya Potti, built with lightweight HTML, CSS, and JavaScript. Includes a pixel-art companion, project filtering, responsive layout, and reduced-motion support.

## Local preview
Run `python3 -m http.server 8000` in the project folder, then open http://localhost:8000.

## Deploy with Render
Choose **New → Static Site**, select `kousalyaa13/kousalya-portfolio`, set **Build Command** to `echo ready` and **Publish Directory** to `.` (a `render.yaml` blueprint is also provided).

## Editing
Project data lives in `script.js`. Update certification entries and experience in `index.html`. Add a PDF as `resume.pdf` and then update the Resume button to point to it. The LinkedIn URL is verified; Medium and resume links are not shown until supplied.

Project images are referenced from existing public GitHub project repositories where possible. All code and assets remain credited to their respective original projects.
